DESPUES DE SUBIR LOS ARCHIVOS
1. Abra Actions.
2. Abra "Build SENDA.V0 Windows Desktop".
3. Pulse "Run workflow" sobre main. No use Re-run jobs de un run viejo.
4. El workflow debe pasar pruebas, crear SENDA.V0.exe, ejecutar --check y publicar la Release v0.4.1.
5. En GitHub abra Releases -> Latest y descargue SENDA.V0_0.4.1_WINDOWS_DESKTOP.zip.
6. Extraiga el ZIP y ejecute INSTALAR_SENDA_V0.bat.

OPCION INSTALAR DESDE GITHUB
Si tiene una copia del repositorio en Windows, puede ejecutar INSTALAR_DESDE_GITHUB.bat. Descarga la Release mas reciente e instala la aplicacion sin borrar los datos existentes.
